M340i Deal Checker

Live

A pricing tool for used BMW M340i listings (2020–2022). A regression fit on 213 active listings estimates a fair price from mileage, model year, drivetrain, and option count, then checks a real asking price against it.

JavaScript, regression modeling, Visor API

  • Model trained on 213 active listings, cross-validated to an average error of about 6% ($2,356)
  • Verdict bands (excellent deal → overpriced) based on percent difference from the model estimate, not a fixed dollar cutoff
  • Data refreshes monthly rather than being a one-time snapshot
